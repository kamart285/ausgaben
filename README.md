# Ausgaben

Kleine Offline-Web-App (PWA) zum schnellen Notieren von Ausgaben: Betrag, Geschäft, Kategorie, Notiz und Beleg-Foto.
Auswertung nach Kategorien, Betragsgröße und Verlauf; Export als CSV (Excel) und JSON-Sicherung inkl. Belegen.

Alle Daten bleiben lokal auf dem Gerät (IndexedDB). Dieses Repository enthält nur den Code.

App: https://kamart285.github.io/ausgaben/
